# Madax Wavies — direct WhatsApp ordering

Zero-commission online ordering for the group's restaurant brands. Customers browse a day-aware
menu and the order opens pre-filled in the branch's own WhatsApp — no Talabat/Deliveroo cut, no
delivery-app middleman. Owners manage the menu, prices, photos and offers from the self-hosted
PHP portal.

## What's here

| Path | Role |
|---|---|
| `index.html` | Customer ordering page + the whole order engine. Menu data lives in the `SHOPS` object near the top. |
| `menu-seed.json` | Same menu, seeded into the database at install time. |
| `menu-index.json` | Flat search index, regenerated by `build.py`. |
| `build.py` | Generates one standalone site per branch into `build/`. |
| `build/` | Eight ready-to-deploy per-branch sites (generated — re-run `build.py` after menu edits). |
| `portal.html` | Owner admin: menu, photos, offers, rewards, branches, logins, export. |
| `dashboard.html` | Control-centre view (orders, revenue, zones). |
| `install.php` | One-time web installer. **Delete it after a successful install.** |
| `api/` | Self-hosted PHP backend (orders, auth, live menu). |

## Deploying

**Static per-branch sites (free, no backend)** — for Google Business Profile order links:

1. `python3 build.py`
2. Netlify → *Add new site → Deploy manually* → drag **one** folder from `build/` onto the drop zone.
3. Rename the site (e.g. `mashad-alqusais`). Repeat per folder.
4. Paste each branch's URL into that branch's Google Business Profile → Ordering → order link.

Each branch's WhatsApp number is baked in via `BRANCH_LOCK`, so orders route correctly with no backend.

**Full system with portal (PHP + MySQL hosting):**

1. Create a MySQL database and user in the hosting panel, then add the user to the database with
   **ALL PRIVILEGES** — the most-forgotten step.
2. Upload everything here to `public_html`, set `photos/` and `api/` to `0755`.
3. Open `https://<domain>/install.php`, fill in the four DB values plus the admin login, submit.
4. **Delete `install.php`.**
5. Sign in at `https://<domain>/portal.html`, change the password, fix the WhatsApp numbers, place
   a test order.

## Editing the menu

Edit the `SHOPS` object in `index.html` (leave the CSS and engine JS below it untouched), mirror the
change into `menu-seed.json`, then re-run `python3 build.py`. Dish photos go in `photos/` named after
each item's `g` slug (`photos/<slug>.jpg`); cards render fine without them.
